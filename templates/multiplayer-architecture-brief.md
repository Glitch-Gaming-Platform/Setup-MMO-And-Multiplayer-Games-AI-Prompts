# Tell the AI About Your Online Game

Copy this sheet, answer what you can, and give it to your AI coding tool.

It is okay to write “I do not know.”

## The game

- Game name:
- What does the player do?
- What was the game made with?
- Where will people play it? Web, PC, phone, or console?
- Is any online code already working?

## The players

- How many players are together?
- Are they fighting, working together, or both?
- Can friends join as a group?
- Can players join after a game starts?
- Can players watch without playing?

## Does the game end?

- Does each match or room end?
- About how long does one game last?
- What disappears when the game ends?
- What should still exist tomorrow?

## Saved progress

- Do players have accounts?
- Should characters be saved?
- Should items or equipment be saved?
- Should coins or money be saved?
- Can players trade?
- Are there quests, guilds, mail, crafting, or housing?
- Does the world itself change and stay changed?

## How players connect

- Should one player host the game?
- Should the game rent a separate computer to run each match?
- Is it okay if the match ends when the host leaves?
- Does the game need matchmaking?
- Does the game need private invites?
- Does the game need voice or text chat?

## What matters most?

- Is this a casual game or a serious ranked game?
- Are rewards valuable?
- How bad would cheating be?
- How bad would losing saved progress be?
- What is the first small online test you want working?
